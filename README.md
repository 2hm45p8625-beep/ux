# 用户体验心理学 课堂互动

第四章、第五章的课堂互动页面。每个页面是一个独立的 html 文件，不用联网加载任何东西。

- `index.html`　入口页：四个互动的链接和二维码
- `ch4/scene.html`　第四章：画像人物的一天 + 场景盲盒
- `ch5/moments.html`　第五章：数一数发朋友圈
- `ch5/game.html`　第五章：情绪过山车侦探
- `ch5/curve.html`　第五章：画出情绪曲线，做“我的旅程图”
- `ch6/`　第六章：五要素小测、SWOT小练习、竞品分析小助手
- `ch7/proto.html`　第七章：原型小助手（理论课练习、实践课AI提示词）
- `teacher/`　老师用：讲课故事地图、第四章演示版

部署到 GitHub Pages 的步骤见 `部署说明.md`。
